# 🎂 Kajal Didi Birthday Surprise 🎉

A magical birthday surprise project made with ❤️ by **Betu** for **Kajal Didi**.  
It unlocks with a countdown ⏳, reveals a surprise cake 🎂, and opens a collection of gifts 🎁 filled with animations, photos, and love.  

HELLO  KAJAL DIDI  -  I  HOPE  YOU  WILL  HAPPY  WITH  MY  EFFORTS 
---

## ✨ Features

- ⏳ **Countdown Timer** – Builds excitement before the surprise unlocks.  
- 🎂 **Birthday Cake Reveal** – Surprise cake animation with heartfelt message.  
- 💌 **Surprise Page** – Opens a hub of gifts with star & ribbon animations.  
- 🎶 **Music** – Plays *Happy Birthday* and *Happy* songs in the background.  
- ❤️ **Gift Pages** –  
  - Gift 1 → Glowing animated heart with a special message.  
  - Gift 2 → Framed photo with fireworks effect.  
  - Gift 3 → Slideshow album of 10 memories.  
  - Gift 4 → Twinkling stars with a love message.  
  - Gift 5 → Cute bouncing balloons.  
  - Gift 6 → Floating candles with glow.  
  - Gift 7 → Sparkling wishes text.  
  - Gift 8 → Rising confetti celebration.  
  - Gift 9 → “Final Surprise” heartfelt message with fireworks.  
  - Gift 10 → Clickable glowing hearts that reveal **HAPPY BIRTHDAY** with fireworks & sparkles 🎆


## 🚀 How to Run

1. Clone this repo:  
   ```bash
   git clone https://github.com/NaviJha/Kajal_didi_birthday_surprise.git
   ```
2. Open `index.html` in your browser.  
3. Wait for the countdown ⏳ and enjoy the surprise 🎉.
